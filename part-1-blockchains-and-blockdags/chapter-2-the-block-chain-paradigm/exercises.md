# Exercises

1. Prove that a (simple undirected graph) is a DAG if and only if there are no two vertices $$A$$ and $$B$$ such that $$A$$ is reachable from $$B$$ _and_ $$B$$ is reachable from $$A$$
2. Prove that a rooted DAG has only one root
3. Show that a rooted DAG is a tree if and only if for any block $$B$$ that is not the root, there is _a single_ path from $$B$$ to the root
